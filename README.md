# Expense Tracker

A JavaScript-based expense tracker for adding, managing, and calculating personal expenses.

## Overview

The Expense Tracker is a frontend web application developed using HTML, CSS, and JavaScript.

Users can enter an expense name and amount, add it to the expense list, and view the automatically calculated total. Individual expenses can also be removed from the list.

## Features

- Add expenses with name and amount
- Display added expenses dynamically
- Automatically calculate the total expense
- Remove individual expenses
- Input validation for invalid or empty values
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Enter the name of an expense.
2. Enter the expense amount.
3. Click **Add Expense**.
4. The expense is added to the list.
5. The total expense is automatically updated.
6. Individual expenses can be removed using the delete button.
